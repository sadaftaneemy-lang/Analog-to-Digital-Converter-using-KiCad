## What is KiCad ??
KiCad is a free, open-source Electronic Design Automation (EDA) tool used to design electronic circuits and Printed Circuit Boards (PCBs). In simple words: 👉 KiCad helps you go from an idea → circuit → PCB → manufacturing files.

Schematic → PCB Layout → Fabrication → Assembly.

KiCad supports every step of this flow.
